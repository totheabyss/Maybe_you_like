Music Discovery API
Python · FastAPI · SQLite · JWT · Pytest · Last.fm API

Uma API para descobrir bandas menos conhecidas a partir dos artistas favoritos do usuário.

Funcionalidades
- Cadastro e autenticação de usuários.
- Autenticação baseada em JWT.
- Gerenciamento de artistas favoritos.
- Recomendações musicais usando a Last.fm.
- Testes automatizados com pytest e mocks.
